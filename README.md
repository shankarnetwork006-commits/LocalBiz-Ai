# TIME QUEST – 3000 BC

Deployable PWA MVP for children.

## Run
Open `index.html` in a browser.

## Vercel
Upload this folder/repository to Vercel. No build command is required.

## Included
- Responsive mobile UI
- Telugu / English toggle
- 6 educational quests
- Coins and XP
- Levels
- Badges
- Local progress saving
- Basic PWA offline caching

## Note
The historical content is intentionally simplified for children. Expand each region/period with source-backed content before publishing as a historical reference.
