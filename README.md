# LocalBiz AI — MVP

Vercel-ready static MVP for a Telugu + English small-business AI assistant.

## Deploy
1. Upload this folder to GitHub.
2. Import the repository into Vercel.
3. Deploy with no build command.

## Important
This MVP is a front-end prototype. The AI assistant responses are demo logic; real AI and WhatsApp messaging require backend/API integration and appropriate business/WhatsApp permissions.
