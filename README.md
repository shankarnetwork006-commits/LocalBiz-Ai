## Run locally
1. Install Node.js 18 or newer.
2. In this folder run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. Run `npm run build` to create the production build in `dist/`.

## Included interactions
- Responsive streaming-style homepage and episode/project rows
- Search across episodes, projects, career entries, and passion cards
- Details modal on each card
- My List toggle and notifications feedback
- About/contact section with email, phone, and LinkedIn links
- Mobile-friendly layout

## Cinematic flow added
